How to interpret the plots

Each point represents one patient. Distances provide an exploratory view of similarities in the NMF component profiles. UMAP axes do not have direct biological meanings; apparent clusters should not be interpreted as evidence of statistically distinct subtypes without independent analyses.

Methods and source code

The full annotated R script, analysis rationale, and data availability information are provided in the accompanying GitHub repository. Publication of the interactive explorer is subject to review of embedded patient-level data and applicable data-use agreements.
